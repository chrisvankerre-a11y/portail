1) Ouvrir l’organigramme

  • Double-cliquez sur org1.html (ou le fichier HTML principal).
  • Le fichier s’ouvre dans votre navigateur (Chrome / Edge / Firefox).
  • Aucune installation n’est nécessaire.
Si vous changez d’ordinateur (ou de navigateur), vous ne retrouverez pas automatiquement vos données : utilisez Export JSON puis Import JSON pour transférer l’organigramme.

2) Comprendre l’interface

En haut

  • 📖 Mode d’emploi : ouvre cette notice.
  • 🖼️ Export PNG : crée une image du schéma.
  • 💾 Export JSON : sauvegarde complète des données.
  • 📥 Import JSON : recharge une sauvegarde JSON.

Navigation & vues

  • Recherche : filtrer par nom / fonction / département.
  • Filtres : fonction, département, collaborateur.
  • Vues Schéma : molette = zoom ; glisser = déplacer ; double-clic = centrer.

3) 💾 Export JSON — sauvegarde complète (recommandé)

Export JSON enregistre l’organigramme au format .json. C’est la méthode à privilégier pour sauvegarder, transférer ou restaurer.

Procédure

  1. Cliquez sur 💾 Export JSON.
  2. Un fichier organigramme.json est téléchargé.
  3. Rangez ce fichier dans un dossier identifié (ex. “Sauvegardes Organigramme”).
Bon réflexe : faites un export avant une grosse modification.

À quoi ça sert ?

  • Revenir en arrière si une erreur est faite
  • Envoyer l’organigramme à quelqu’un
  • Changer d’ordinateur / navigateur
Attention : si vous perdez ce fichier ET que votre navigateur efface ses données (nettoyage, changement de PC), vous ne pourrez pas récupérer l’organigramme.

4) 📥 Import JSON — restaurer / charger une sauvegarde

Import JSON charge un fichier .json précédemment exporté.

Procédure

  1. Cliquez sur 📥 Import JSON.
  2. Sélectionnez votre fichier organigramme.json.
  3. L’organigramme se met à jour immédiatement.
L’import remplace l’organigramme actuel. Avant d’importer, faites un Export JSON si vous voulez conserver l’état actuel.

Si ça échoue

  • Vérifiez que le fichier est bien un .json.
  • Si un message “JSON invalide” apparaît, le fichier n’a pas le bon format.

5) 🖼️ Export PNG — créer une image

Export PNG crée une image du schéma (utile pour imprimer, envoyer par e-mail, coller dans un document).

Procédure

  1. Allez dans une Vue Schéma (verticale ou horizontale).
  2. Ajustez le zoom / déplacement si nécessaire.
  3. Cliquez sur 🖼️ Export PNG.
  4. Un fichier organigramme.png est téléchargé.
Le PNG est une photo du schéma : on ne peut pas ré-importer un PNG comme des données. Pour sauvegarder “l’organigramme modifiable”, utilisez Export JSON.

6) Sauvegarde automatique

L’application mémorise automatiquement les données et certains réglages (recherche, filtres…) sur cet ordinateur et ce navigateur.

Cette sauvegarde automatique ne remplace pas un Export JSON si vous devez transférer ou archiver.

7) Dépannage (rapide)

Problème Solution
Le fichier ne s’ouvre pas correctement Ouvrez avec Chrome / Edge / Firefox (pas Word). Double-cliquez sur le fichier HTML.
Import JSON impossible Vérifiez que le fichier est bien .json et provient d’un Export JSON.
Je ne retrouve plus mes données Rechargez votre dernière sauvegarde via Import JSON. Sinon, elles ont probablement été effacées côté navigateur.
Je veux partager une version “image” Utilisez Export PNG depuis la vue schéma.
Je veux partager une version modifiable Utilisez Export JSON.
Astuce : vous pouvez imprimer cette page (bouton 🖨️) et choisir “Enregistrer en PDF”.
