Notice d’utilisation — Dashboard DG

Mode d’emploi simple pour gérer chefs d’opérations, accountables, tâches et projets.

Sommaire

1) À quoi ça sert 2) Se repérer 3) Importer (Excel) 4) Exporter 5) Tâches 6) Projets + phases 7) Sauvegarde complète 8) Sauvegarde en ligne (Gist) 9) Réinitialiser 10) Bons réflexes

1) À quoi ça sert

Le Dashboard DG permet de :

  • tenir la liste des chefs d’opérations et des accountables,
  • suivre des tâches (avec détails, risques et plans d’action),
  • suivre des projets (avec dates et phases).
Important : vos données restent disponibles sur l’ordinateur où vous utilisez le dashboard.

2) Se repérer

Le menu à gauche donne accès à :

  • Accueil : import/export et sauvegardes
  • Liste des chefs d’opérations
  • Liste des accountables
  • Toutes les tâches
  • Liste des projets

Dans les listes, cliquer sur un nom ou un compteur permet souvent de filtrer.

3) Importer des données (Excel)

Depuis Accueil → Importer des données, choisissez le type (chefs d’opérations, accountables, tâches, projets), sélectionnez votre fichier Excel, puis lancez l’import.

Attention : pour les tâches et projets, les noms de “Responsable” et “Accountable” doivent être écrits exactement comme dans vos listes.

Formats attendus

Fichier Colonnes
Chefs d’opérations ID, Nom, Rôle
Accountables ID, Nom, Rôle
Fichier Colonnes
Tâches ID, Responsable, Accountable, Titre, Description
Projets ID, Responsable, Accountable, Titre, Description, Date Début, Date Fin

Dates (projets)

  • Vous pouvez utiliser YYYY-MM-DD ou DD/MM/YYYY.

Astuce : pour être sûr d'importer au bon format, réaliser d'abord un export, modifiez-le puis réimportez-le.

4) Exporter

Depuis Accueil (ou depuis chaque section), utilisez les boutons Exporter pour générer un fichier Excel.

Astuce : exporter avant une grosse modification permet de garder une copie simple.

5) Tâches

Voir les tâches

  • Menu → Toutes les tâches
  • Cliquer sur le titre d’une tâche pour ouvrir sa fiche
  • Cliquer sur le nom d’un responsable / accountable pour filtrer

Modifier une tâche

Dans la fiche d’une tâche, cliquez dans un champ pour le modifier (titre, description, objectifs, commentaires, etc.).

Les modifications sont enregistrées quand vous sortez du champ.

Risques et plans d’action

  • Cliquer sur Ajouter un risque avec plan d’action
  • Remplir le “Risque” et le “Plan d’action” associé
  • Vous pouvez supprimer un risque via le bouton ×

Supprimer une tâche

Dans la fiche d’une tâche : bouton Effacer la tâche (confirmation demandée).

6) Projets + phases

Ouvrir un projet

Menu → Liste des projets, puis cliquez sur le titre d’un projet pour voir ses détails.

Modifier un projet

  • Titre, description
  • Date de début / date de fin

Ajouter des phases

Dans un projet, section “Phases du projet” :

  • Cliquer sur Ajouter une phase
  • Indiquer un titre, une date, et une description (facultatif)

Supprimer un projet

Attention : supprimer un projet est irréversible.

7) Sauvegarde complète (fichier)

Sur Accueil → “Sauvegarde complète” :

  • Exporter HTML : télécharge un fichier de sauvegarde complet (à conserver)
  • Importer HTML : restaure une sauvegarde (remplace tout ce qui existe)
  • Exporter HTML statique : génère un document “lecture seule” pratique pour partager
Importer remplace toutes les données actuelles.

8) Sauvegarde en ligne (Gist)

En bas de page, vous avez :

  • Charger (Gist) : récupère la sauvegarde en ligne
  • Sauvegarder (Gist) : envoie vos données en ligne

Lors de la première sauvegarde, un code personnel GitHub peut être demandé. Si une version plus récente existe en ligne, une proposition de chargement peut apparaître.

9) Réinitialiser

Réinitialiser supprime toutes les données (chefs d’opérations, accountables, tâches, projets).

À utiliser uniquement si vous voulez repartir de zéro.

10) Bons réflexes

  • À faire Faire une sauvegarde complète avant de gros changements.
  • À faire Vérifier l’orthographe exacte des noms avant import (tâches/projets).
  • À surveiller Conserver vos fichiers d’export (Excel et sauvegarde complète) dans un dossier dédié.
  • À éviter Importer un fichier de sauvegarde si vous n’êtes pas sûr : cela remplace tout.
