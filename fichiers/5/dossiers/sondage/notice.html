📘 Mode d'emploi

1. Fonctionnement général

Cet outil permet de collecter des disponibilités sans base de données. Les participants génèrent un code qui est ensuite importé dans le tableau global.

2. Pour l'organisateur

  • Configurer les dates et créneaux dans le formulaire
  • Générer la version finale
  • Envoyer le fichier aux participants
  • Importer les codes reçus dans le tableau récapitulatif

3. Pour les participants

  • Entrer leur nom
  • Sélectionner leurs disponibilités
  • Cliquer sur "Générer le code"
  • Envoyer le code par email

4. Import des réponses

Dans le tableau récapitulatif :
  • Coller le code reçu
  • Cliquer sur "Importer"
Les données sont enregistrées automatiquement dans le navigateur.

5. Export et partage

Vous pouvez :
  • Exporter en HTML
  • Exporter en JPG
  • Générer un lien partageable
⚠️ Ne collez jamais un code provenant d’une source inconnue.
