Mode d’emploi — Répartition du prizepool

Cette page explique comment utiliser l’outil de répartition du prizepool (montants, paliers, export).

← Retour au calcul

1) Remplir les champs

  • Joueurs : nombre total d’inscrits au tournoi.
  • Prizepool (€) : montant total à répartir.
  • Premier prix (€) (optionnel) : mets un montant si tu veux imposer un 1er prix exact. Sinon, laisse vide.
  • Minimum dernière place (€) (optionnel) : mets un plancher si tu veux garantir un minimum à la plus petite place payée. Sinon, laisse vide.

2) Régler l’écart minimal entre paliers

Choisis 2%, 4%, 6%, 8% ou 10% pour imposer un écart minimal entre deux paliers consécutifs.

Plus l’écart est élevé, plus le programme peut refuser certains paramètres (par exemple si le 1er prix est trop bas pour tenir le minimum du bas).

3) Lancer le calcul

  • Clique sur Calculer.
  • Le tableau affiche pour chaque place : le pourcentage et le montant en euros.
  • Une ligne Total permet de vérifier que l’ensemble retombe bien sur 100% et sur le prizepool.

4) Exporter / copier

  • Exporter Excel (CSV) : télécharge un fichier que tu peux ouvrir dans Excel.
  • Copier (TSV) : copie les données pour les coller directement dans un tableur.
Astuce : si tu vois “Rien à exporter” / “Rien à copier”, c’est qu’aucun calcul n’a été lancé (clique d’abord sur Calculer).

5) Messages d’erreur possibles

  • Minimum trop élevé : le plancher demandé ne peut pas être tenu avec le nombre de places payées et le prizepool.
  • Premier prix dépasse le prizepool : le 1er prix imposé est supérieur au total.
  • Contraintes trop fortes : l’écart minimal (et/ou le couple “1er prix + minimum bas”) empêche d’atteindre exactement le prizepool.

6) Licence (si un écran s’affiche au démarrage)

  • Avertissement : la licence arrive bientôt à échéance. Tu peux continuer ou entrer un code pour prolonger.
  • Licence expirée : il faut entrer un code de renouvellement pour continuer.

Si un code est demandé, saisis-le puis clique sur Valider le code.
